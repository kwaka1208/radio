## 4. 番組カバー画像（OGP・左パネル）の配置修正

- `starpod.config.ts` の `image: '/images/radio.png'` は **`public/` から配信**されるため、
  ファイルを配信対象に移動: `src/images/radio.png` → **`public/images/radio.png`**
  - `show.image` は素の URL 文字列として使われ Astro の画像パイプラインを通らないため、
    `public/` に無いと 404 になる（OGP画像が反映されなかった原因）。
- OGP の絶対URL（`https://radio.crssrds.jp/...`）は仕様上正しい挙動なので変更しない。

## 5. 音声URLをルート相対にしてローカル再生に対応

**方針**: ページが自分で使う URL はルート相対（`/episodes/...`）、
仕様上フルURLが必須な所（RSS・OGP・JSON-LD）だけ絶対URL化する。

- `src/lib/rss.ts`: `audio.src` を絶対URL → **ルート相対 `/episodes/${data.audio}`**
- `src/pages/rss.xml.ts`: `<enclosure>` を `new URL(episode.audio.src, siteUrl)` で絶対URL化
- `src/pages/[episode].astro`: JSON-LD `contentUrl` と `og:audio` を `new URL(..., Astro.site)` で絶対URL化
- 効果: dev ではプレイヤーが localhost の音声を、本番では `radio.crssrds.jp` を参照。**本番出力は不変**。
- ローカル再生には `public/episodes/001.mp3` 等に音声を置く必要あり（音声はリポジトリ管理外）。

## 6. 開発サーバー時に localhost を使う + フォントを crssrds.jp に合わせる

### site の dev/prod 切替（`astro.config.mjs`）
- `const isDev = process.argv.includes('dev')` を追加、`server: { port: 4321 }` を明示
- `site: isDev ? 'http://localhost:4321' : 'https://radio.crssrds.jp'`
- `src/pages/[episode].astro`: canonical の基準を `Astro.url` → **`Astro.site`** に統一（他ページと挙動を揃える）
- 効果: dev では canonical / og:url / og:image / RSS / sitemap 等が localhost、
  `astro build` では本番URL。**本番出力は不変**。

### フォント（Google Fonts の Inter → システムフォント）
- `astro.config.mjs`: `fonts:` ブロックと `fontProviders` の import を削除（Google Fonts 依存を撤去）
- `src/layouts/Layout.astro`: `<Font>` と `import { Font }` を削除、`<body>` を `font-inter` → `font-jp`
- `src/styles/tailwind.css` の `@theme` に crssrds.jp と同じシステムフォントスタックを定義:
  - `--font-jp: -apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Yu Gothic', 'Meiryo', 'Helvetica Neue', Arial, sans-serif`
  - `--font-en: -apple-system, BlinkMacSystemFont, 'Helvetica Neue', Helvetica, Arial, sans-serif`
- 効果: Web フォント読み込みが消え、body が Tailwind v4 の `font-jp` ユーティリティ（システムスタック）に。
